## 关于本站

这是一个用于 Flint 集成测试的完整站点。

### 功能特性

本站点包含以下功能：

1. **多种 Front Matter 格式**
   - YAML 格式
   - TOML 格式
   - JSON 格式

2. **短代码支持**
   - figure
   - highlight
   - gist
   - youtube/vimeo

3. **分类系统**
   - 分类（Categories）
   - 标签（Tags）
   - 系列（Series）

4. **资源处理**
   - SCSS 编译
   - JavaScript 处理
   - 图片优化
