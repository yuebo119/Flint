最近替换了两个日常工具，记录一下切换理由。

## 终端模拟器

从经典款换成了 GPU 加速款，滚动不再卡顿，连大日志文件也顺滑。
配置迁移半小时，收益每天可见。

## HTTP 调试

curl 依然是脚本里的王者，但手工调试换成了带请求历史的图形客户端：
请求可以命名、分组、重放，调试 cookie 与 header 也直观得多。

工具替换的判断标准只有一条：**切换成本要在一个月内赚回来**。
赚不回来的，忍着旧工具的毛病也比折腾强。
