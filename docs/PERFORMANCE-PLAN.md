> 依据：benchmarks/SUMMARY.md 三轮实测数据 + 已知局限清单

## 全程纪律

1. 每批开始：S1 基线快照（命令 + 退出码 + 关键数字）记录在案
2. 每次只改一个变量，改完即测即记录（S2）
3. 任何优化因子采纳前反向验证：移除后必须退化回基线，否则丢弃（S3）
4. 修复尝试 ≤3 次：分析 → 针对性修复 → 换方案 → 报告停止
5. 每批完成即 commit（`checkpoint: 批次N-<里程碑>`），文档同批同步（三方一致）
6. 长任务进度汇报：总体百分比 + 累计已完成 + 未完成 + 下一步
