# .ai/prompts

审计与性能轮的提示词，以及配套的起点自检探针。放这里是为了让流程在仓内可复现：提示词、探针、判读规则都在版本控制里，换人或换会话不必重新口述。

## 文件

| 文件 | 用途 |
| --- | --- |
| `flint-perf-first-prompt.md` | 性能优先轮的主提示词。性能是主目标，正确性与安全是门禁。当前推荐版本 |
| `fix-presence-probe.sh` | 起点自检：按锚点 grep 本项目历次审计的修复标记，输出 PRESENT / ABSENT |

## 用法

性能轮：

```bash
bash .ai/prompts/fix-presence-probe.sh          # 全 PRESENT 才继续
# 然后把 flint-perf-first-prompt.md 全文作为任务提示词交给执行方
```

探针出现 `ABSENT` 时必须先停下报告：它意味着起点不是预期的代码状态（例如分支未同步），
此时做性能优化会把"已知缺陷的影响"混进基线。

## 维护

- 探针新增条目时，同时把它对应的修复锚点写进提示词的"已知事实"或代码注释，避免探针与代码脱节。
- 修复若被回滚，探针会自然变红，这是预期行为，不要为了让探针变绿而放宽匹配串。
- 提示词的版本与日期写在文件头；口径变化（例如构建形态、测试通道）要在同一提交里同步。
